# Workshop slides

`google-adk-voice-agents-workshop.pptx` is the offline PowerPoint copy of the workshop deck.

The live presentation is available in [Google Slides](https://docs.google.com/presentation/d/1n0RPi-yYbqH_e_r23KlJAldgGFxdpRez7lVCUqkLLc0/edit).

The deck follows the same checkpoint order as the repository, so the presenter can move participants to a completed checkpoint whenever someone gets stuck.
